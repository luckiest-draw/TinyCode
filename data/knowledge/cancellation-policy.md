# Cancellation policy

This document is a fictional store policy written for demo and testing purposes.

## When an order can be cancelled

An order can be cancelled by the customer while it is still in `processing`
status, that is, before it has been handed to the carrier.

Once an order has moved to `shipped` or `delivered` status, it can no longer
be cancelled through self-service. In that case the customer may start a
return instead once the order is delivered.

## How to cancel

To cancel an order, the customer submits the order id through support or the
account order page. A cancellation is confirmed only when the order status
changes to `cancelled`.

## Refund after cancellation

When an order is cancelled before shipment, the full order total is refunded
to the original payment method. Refunds typically appear within 3 to 7
business days depending on the payment method.

## Orders that cannot be cancelled

An order cannot be cancelled if it has already been shipped, if it contains a
digital item that was delivered immediately, or if a return request for the
same order is already open.
